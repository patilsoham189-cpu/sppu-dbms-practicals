# SPPU Database Management Systems (DBMS) Laboratory Practicals

Comprehensive collection of Database Management Systems laboratory assignments, SQL schemas, PL/SQL scripts, MongoDB queries, and JDBC implementations aligned with the **Savitribai Phule Pune University (SPPU)** Computer Engineering curriculum.

---

## 📑 Curriculum & Syllabus Breakdown

### 🔹 Group A: Relational Database Management Systems (RDBMS & SQL/PL-SQL)

| Practical | Topic / Assignment | Tech Stack |
| :--- | :--- | :--- |
| [`practical-01/`](./practical-01/) | ER Modeling, Relational Schema Design & Integrity Constraints | SQL / Relational Algebra |
| [`practical-02/`](./practical-02/) | SQL Data Definition (DDL) and Data Manipulation (DML) Queries | MySQL / Oracle SQL |
| [`practical-03/`](./practical-03/) | Complex SQL Queries, Aggregations, Group By, Having Clauses | SQL |
| [`practical-04/`](./practical-04/) | Relational Joins (Inner, Left, Right, Full Outer) & Subqueries | SQL |
| [`practical-05/`](./practical-05/) | Views, Indexes, Sequences & Schema Integrity Constraints | Oracle SQL / MySQL |
| [`practical-06/`](./practical-06/) | PL/SQL Control Structures & Exception Handling Blocks | PL/SQL |
| [`practical-07/`](./practical-07/) | Explicit, Implicit & Parameterized Cursors in PL/SQL | PL/SQL |
| [`practical-08/`](./practical-08/) | Database Triggers (Row-level, Statement-level, Audit Logging) | PL/SQL Triggers |
| [`practical-09/`](./practical-09/) | Database Connectivity (JDBC) with Relational Databases | Java & MySQL |

## 🛠️ Environment & Prerequisites
- **Relational Databases:** MySQL 8.0+ / Oracle 11g/19c
- **NoSQL Database:** MongoDB 6.0+
- **Languages:** SQL, PL/SQL, Java (JDK 17+)
- **Tools:** MySQL Workbench, MongoDB Compass, mongosh, VS Code
